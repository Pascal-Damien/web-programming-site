From idea to global network

The World Wide Web was created by Tim Berners-Lee at CERN. His goal was to make it easier for researchers to share information using linked documents on the internet.

Important milestones

1989
Tim Berners-Lee proposed a system for sharing information over the internet.
1990
The first web browser, web server, and website were created at CERN.
1991
The World Wide Web became available to the public.
1993
CERN released web technology into the public domain, helping the web grow rapidly.
1994
The World Wide Web Consortium (W3C) was founded to develop open web standards.
2000s
Blogs, social networks, online video, and interactive web applications became widespread.
Today
The web connects billions of people through accessible, mobile, and increasingly interactive services.

Web and internet: what is the difference?

The internet is the global network of connected computers. The web is a service that runs on the internet and uses technologies such as HTML, HTTP, and URLs to connect and display information.
